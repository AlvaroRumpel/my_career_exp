# Game Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fluxo único Pré → jogo em andamento → Pós (spec docs/superpowers/specs/2026-08-12-game-flow-design.md), remoção do campo de data e correção do overflow mobile do Pós-jogo.

**Architecture:** Campo type-only `pendingContext` em `Career`; Pré-jogo seta/cancela; Pós-jogo dispatch em 3 estados (resultado → bloqueado → formulário); ack limpa `lastResult`.

**Tech Stack:** igual ao projeto (React 19, Tailwind v4, vitest).

## Global Constraints

- Engine: só a linha do tipo em `src/engine/types.ts`. Nenhuma lógica.
- Carreiras salvas sem `pendingContext` seguem válidas (`undefined` = sem jogo).
- Após cada task: `npx tsc -b` + `npx vitest run` verdes; commit.
